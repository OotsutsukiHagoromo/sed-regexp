# Ошибка компиляции в gsed
gsed: file yo.sed line 58472: invalid reference \2 on 's' command's RHS

# Что ещё можно засунуть в регулярки
Здесь имеются в виду регулярки для конвертирования текстового файла в .tex

* Проставлять тонкую шпацию `\,` между последней цифрой и сокращениями «г.», «руб.»
* Убрать автозамену дефисов на `"=`, если это — ссылка. 
* Для компиляторов, отличных от pdflatex – заменять сокращение «руб.» на знак рубля `₽`
